# 溯流常用页 · Argon 实施说明

## 产品范围

把 LuCI 中高频任务组织成「总览、设备、网络、服务、系统」。默认仍显示完整菜单。用户选择「显示常用菜单」后，启用简化导航和高频页面引导；选择「显示完整菜单」可立即恢复原版。选择仅保存在当前浏览器，不改变路由器配置。

| 入口 | 直接复用的实际页面 |
| --- | --- |
| 总览 | LuCI 原生状态总览、实时带宽、系统日志 |
| 设备 | 溯流设备清单和设备详情，包括设备实际可用的 IP、映射、DDNS 功能 |
| 网络 | 接口、无线、DHCP/DNS、防火墙区域和原生端口转发 |
| 服务 | 已安装且账户可见的溯流 DDNS、消息通知、证书 |
| 系统 | 系统设置、管理访问、备份与升级 |

简化的是入口和阅读顺序，不是用一套新表单替代真实功能。常用总览保留下面的 LuCI 实时组件；带宽入口直接打开原生的实时图。设备、网络、服务和系统页面继续使用自己的真实数据、保存、校验和应用行为，不生成模拟数据，不改原表单、后端、权限、登录、网络配置或服务部署。缺少可选插件或权限时不添加无效入口；完整菜单继续可用。

## 实施边界与验收

- 基线是 fork 的 Argon 3.2.0（`5d6a6e8b86ea9aee0f3cbb9637f9140414153a45`）。Mac 上固件源码所用的 3.0.0 固定版不是此次变更的直接安装目标。后续先确定固件使用的 Argon 版本，再进入构建验收。
- 入口只依据浏览器已获取的 LuCI 原生菜单树，不增加 RPC 或 ACL。优先选择实际可见的细分页面；可选项不显示不代表安装失败。
- 常用导航与原版导航使用同一个 Argon 移动侧栏；样式作用域独立，采用墨色、青绿和暖白，适配已有深色偏好。登录页不加载这一层的样式或脚本。
- 在正式目标固件验收：有/无插件和受限账号；窄屏、深色、键盘焦点；实时图有真实采样；设备和网络页面能正常保存与应用；高频页切回完整模式后没有引导覆盖；不影响路由器登录、原生表单、退出登录和系统升级入口。该分支本身不构建、部署或发布固件。
